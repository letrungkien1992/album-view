# Albums Source

Cau truc mac dinh:

- `src/albums/<folder-1>/<image-files>`
- `src/albums/<folder-2>/<image-files>`

Quy uoc:

- Moi thu muc con trong `src/albums` duoc xem la 1 album.
- Ten thu muc la ten album.
- Tat ca file anh trong thu muc do se duoc load tu dong.

Mo file `resources/album-resource/album-viewer.html` qua local server co directory listing de jQuery doc duoc danh sach file.
